# Marina Mulliner — portfolio preview

A static, editorial portfolio prototype. Run it with:

```bash
npm run dev
```

Then open `http://localhost:4173`.

## Artwork handoff

The project workspace did not contain the referenced artwork attachments. Files in `public/art/` are clearly provisional, locally generated visual stand-ins used to demonstrate composition and interaction; they are not presented as titled or catalogued Marina Mulliner works. Replace `work-1.svg` through `work-8.svg` with approved, web-optimised photographs using the same names (or update the `works` array in `src/main.js`). Rebuild installation views from those approved sources before publication.

The biography, studio email, Instagram URL, and form delivery are also intentionally provisional and should be replaced with approved details before publishing.
